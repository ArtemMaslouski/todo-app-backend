# Todo App Backend

REST API для управления задачами (To-Do list), разработанный на NestJS.

## 🛠 Стек технологий

- **Backend:** Node.js, NestJS, TypeScript
- **База данных:** PostgreSQL
- **ORM:** TypeORM
- **Аутентификация:** JWT (Access + Refresh tokens)
- **Документация:** Swagger

## 🚀 Реализованный функционал

- Регистрация и авторизация пользователей (JWT).
- Защита роутов с помощью Guards.
- CRUD операции для задач (создание, чтение, обновление, удаление).
- Валидация входящих данных через DTO и `class-validator`.

## 📁 Архитектура проекта

Проект построен по модульному принципу:

- `src/modules/auth` — аутентификация и авторизация.
- `src/modules/user` — управление пользователями.
- `src/modules/task` — управление задачами.

## ⚙️ Как запустить локально

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/ArtemMaslouski/todo-app-backend.git

   ```
2. Установите зависимости:
   npm install

3. Создайте файл .env на основе .env.example и заполните переменные окружения(порт,строка подключенія к БД, секрет для JWT)
4. Запустите проект в режиме разработки

   npm run start:dev

5. Для запуска базы данных запустите:

   docker-compose up -d
